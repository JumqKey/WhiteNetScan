**WhiteNetScan** — это безопасный CLI-инструмент для анализа *белых IP-диапазонов* и проверки доступности сайтов с целью **распознавания активного блокирования со стороны интернет-провайдера**.

Проект создан для диагностики ситуаций, когда провайдер избирательно ограничивает доступ к определённым сетям, сервисам или платформам, при этом оставляя доступ к «разрешённым» ресурсам.

> Коротко: **WhiteNetScan = анализ “Белых списков” + проверка доступности сайтов**  
> Без скрытого сканирования, без обхода блокировок, без эксплуатации.

## ⚠️ Важное предупреждение

WhiteNetScan **НЕ**:
- не обходит DPI / фильтрацию
- не предназначен для атак или разведки
- не инструмент анализа сети

Инструмент работает **исключительно в безопасном режиме**:
- IP-диапазоны TCP Запросы на 443 (общее количество айпи с одной зоны 256 IP) 
- проверки сайтов выполняются через обычный DNS и опциональный HTTPS `HEAD`

---

## 🎯 Назначение проекта

WhiteNetScan предназначен для:

- анализа **белых IP-диапазонов** (Cloud / CDN / Hosting)
- подсчёта количества IP-адресов в подсетях
- выявления различий в доступности:
  - между “разрешёнными” сайтами
  - популярными зарубежными сервисами
- диагностики **селективного блокирования провайдером**

Типичные сценарии:
- интернет работает, но зарубежные сервисы недоступны
- часть облачных подсетей недоступна, часть — доступна
- необходимо зафиксировать поведение провайдера без нарушения закона

# 🖥 Использование

- scan <mode> [options]
- 🔹 Режимы работы
- 1️⃣ Скан Белых Списков
- Анализ заранее заданных IP-диапазонов (Cloud / CDN / Hosting).

```bash
scan whitelist
```
# Вывод:

- CIDR-подсеть
- владелец (провайдер / облако)
- ASN
  - назначение
  - количество IP-адресов

# Полный вывод (каждый IP, локально)

```bash
scan whitelist --full
```
- ⚠️ Не отправляет сетевые пакеты.
- IP-адреса не пингуются, а лишь перечисляются из CIDR.

# 2️⃣ Популярные зарубежные сайты
- Проверка доступности популярных иностранных сервисов.

```bash
scan popular
```
- По умолчанию:

- только DNS-резолв

# Дополнительно HTTPS HEAD:

```bash
scan popular --http
```
- Примеры сайтов:

  - GitHub

  - Netflix

  - WhatsApp

  - Telegram

  - Roblox

#3️⃣ Разрешённые сайты (РФ)
- Проверка сайтов, которые обычно находятся в “разрешённой зоне” у провайдеров.

```bash
scan allowed
```
- Включает:

  - госуслуги

  - сайты госорганов

  - Яндекс и связанные сервисы

  - маркетплейсы

  - СМИ

  - операторов связи

- С HTTPS HEAD:

```bash
scan allowed --http
```
# 📊 Статистика
- После каждого запуска выводится краткая статистика:

  - количество доступных DNS-ответов

  - количество успешных HTTP-ответов (если включено)

  - подтверждение отсутствия сетевого сканирования IP

# 🛡 Безопасность и легальность
- WhiteNetScan:

  - не маскирует трафик

  - использует честный User-Agent

  - имеет rate-limit

  - не генерирует подозрительную нагрузку

- Инструмент подходит для:

  - личной диагностики

  - технического анализа

  - документирования поведения провайдера

# 🧠 Философия проекта
- Если доступ к одним сетям есть,
- а к другим — системно отсутствует,
- это не “проблемы интернета”, а политика фильтрации.

- WhiteNetScan помогает это зафиксировать, а не обойти.
