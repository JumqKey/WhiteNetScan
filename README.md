# WhiteNetScan Powered By Community



**WhiteNetScan** — это CLI-инструмент для анализа *белых IP-диапазонов* и проверки доступности сайтов с целью **распознавания активного блокирования со стороны интернет-провайдера**.

Проект создан для диагностики ситуаций, когда провайдер избирательно ограничивает доступ к определённым сетям, сервисам или платформам, при этом оставляя доступ к «разрешённым» ресурсам.

# Быстрая Установка
```bash
apt update 
apt install -y pipx python3-venv git
pipx ensurepath
export PATH="$PATH:/root/.local/bin"

pipx install --force git+https://github.com/JumqKey/WhiteNetScan.git
```
- ## Обновление
```bash
pipx upgrade whitenetscan
```
# Установка на Windows
```bash
git clone https://github.com/JumqKey/WhiteNetScan

cd WhiteNetScan
cd src
cd whitenetscan

python cli.py
```
- необходимо установить Python если у вас его нет.

## ⚠️ Важное предупреждение

WhiteNetScan **НЕ СОЗДАН ДЛЯ**:
- Эксплуатаций в плохих намерениях.
- Для атак или разведки.
- Не инструмент анализа сети

Инструмент работает **исключительно в рамках проверки доступности**:
- IP-диапазоны TCP Запросы на 443
- проверки сайтов выполняются через обычный DNS и опциональный HTTPS `HEAD`

---

## 🎯 Назначение проекта

WhiteNetScan предназначен для:

- анализа **белых IP-диапазонов** 
- подсчёта количества IP-адресов в подсетях
- выявления различий в доступности -
  - между “разрешёнными” сайтами
  - популярными зарубежными сервисами
- диагностики **селективного блокирования провайдером**

Типичные сценарии:
- интернет работает, зарубежные сервисы недоступны
- часть облачных подсетей недоступна, часть доступна
- необходимо пометить поведение провайдера без нарушения закона

# 🖥 Использование

- scan <mode> [options]
- Режимы работы
- Скан Белых Списков
- Анализ заранее заданных IP-диапазонов
```bash
scan whitelist
```
# Вывод:

- CIDR-подсеть
- владелец (провайдер)
- ASN
  - назначение
  - количество IP-адресов

# Полный вывод (каждый IP, локально)

```bash
scan whitelist --full
```
- ⚠️
- IP-адреса не пингуются, а лишь перечисляются из CIDR.

# 2️⃣ Популярные зарубежные сайты
- Проверка доступности популярных иностранных сервисов.

```bash
scan popular
```
- По умолчанию:

- только DNS-резолв

# Дополнительно HTTPS HEAD:

```bash
scan popular --http
```
- Примеры сайтов:

  - GitHub

  - Netflix

  - WhatsApp

  - Telegram

  - Roblox

# 3️⃣ Cайты/Сервисы (РФ)
- Проверка сайтов РФ

```bash
scan allowed
```
- Включает:

  - госуслуги

  - сайты госорганов

  - Яндекс и связанные сервисы

  - маркетплейсы

  - СМИ

  - операторов связи

- С HTTPS HEAD:

```bash
scan allowed --http
```
# Статистика
- После каждого запуска выводится краткая статистика:

  - количество доступных DNS-ответов

  - количество успешных HTTP-ответов (если включено)

  - подтверждение отсутствия сетевого сканирования IP
